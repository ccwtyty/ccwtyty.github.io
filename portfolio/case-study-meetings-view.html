Meetings View on Mobile

A dedicated meetings hub in OneDrive mobile that surfaces relevant meeting files, recordings, and notes in one place — reducing the friction of hunting across Teams, Outlook, and OneDrive after every call.

Product Designer · Android iOS

🎯 Problem

After a meeting, users had to hunt across Teams, Outlook, and OneDrive to find recordings, shared files, and notes — a fragmented experience that caused important content to go unfound and underused. OneDrive sat on all this meeting-adjacent data but had no surface that made it discoverable in context.

💡 Solution

Designed a dedicated Meetings pivot in OneDrive Mobile — a hub that surfaces meeting files, recordings, and notes by meeting context rather than by file type or date. Research validated the mental model: users think "what was from that Thursday call?" not "where did I put that PPTX?"

🔀 Flows

[ Meetings pivot — grouped by meeting context ]
Primary FlowSurfaces all files, recordings, and notes from a meeting together — one tap from any recent meeting in the hub.
[ Meeting detail — files + recording + notes ]
Meeting DetailConsolidated view of everything associated with a single meeting — no switching between apps to piece it together.

🧠 Key Decisions

  • Organized by meeting context, not file type. Users think in meetings, not in file categories. Grouping by meeting rather than by recents or file type matched the actual mental model — validated in research.
  • Tradeoff accepted: requires calendar integration. The pivot is only as useful as the meeting data it can access. Designed clearly for the connected-account state and the graceful empty state for users without calendar integration.
  • Constraint designed around: cross-app data dependencies. Meeting files live in different services — Teams recordings in Teams, shared files in OneDrive, notes in Loop. Surface design had to work with partial data and degrade gracefully when not everything was available.

🤝 Collaboration

Worked with PM, Engineering, and Research. Coordinated with Teams and Outlook partners on data contracts for meeting file and recording surfacing. Led requirements documentation and spec delivery for the mobile pivot design.

📊 Impact

Results
  • Designed end-to-end meetings hub from research through production spec
  • Established OneDrive Mobile as a post-meeting destination, not just a file store
  • Cross-app data contracts with Teams and Outlook defined and documented for engineering

📖 Learning

Designing for cross-app data means designing for partial states first — the empty state and the degraded state are just as important as the ideal state, because users will hit them constantly during rollout.
