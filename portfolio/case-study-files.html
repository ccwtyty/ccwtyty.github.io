Modernizing the Files Experience

Redesigning the Files Hub for clarity, speed, and accessibility — fixing years of incremental inconsistency and laying the foundation for GA-quality mobile release.

Product Designer · Android iOS Shipped

🎯 Problem

As OneDrive mobile evolved, core navigation, creation flows, and accessibility needed polish and consistency to support a GA-quality release. The Files experience had grown incrementally — each feature added with minimal coordination — resulting in visual inconsistency, duplicated patterns, and a surface increasingly difficult to maintain or extend.

💡 Solution

Contributed to OD3 mobile design across Files and Photos — focusing on navigation updates, Create flows, accessibility specs, and bug resolution. Unified recents, offline, and cloud files under a consistent Gen3 architecture that became the foundation for downstream feature work.

🔀 Flows

[ FAB + Create / Upload paths ]
Create & UploadStreamlines scanning, uploads, and folder creation — primary actions surfaced in thumb-reachable zones.
[ Drawer + pivot navigation updates ]
Navigation & Account SwitchingImproves clarity across accounts and content types — reduced nav states match actual task frequency.

🧠 Key Decisions

  • Accessibility baked in, not bolted on. Defined contrast ratios, swipe order, and TalkBack behavior up front — not as a post-ship audit. This directly reduced the number of accessibility bugs in QA.
  • Consistency over novelty. Aligned patterns across iOS and Android rather than optimizing each platform independently. File consistency creates more user confidence than any individual feature.
  • Treated bug fixing as product quality work. Created bug-bash artifacts and improved filing quality, accelerating engineering resolution and reframing polish work as intentional product investment.
  • Maintained cross-app file contracts. Close coordination with Teams and Outlook partners ensured the updated components behaved consistently when surfaced inside other Microsoft apps.

🤝 Collaboration

Worked closely with Design, Engineering, and Content. Created bug-bash artifacts and improved filing quality to accelerate fixes. Coordinated with Teams and Outlook partners to maintain cross-app component contracts throughout the Gen3 migration.

📊 Impact

Results
  • Improved beta feedback on usability and visual cohesion
  • Reduced design bugs and handoff friction through improved spec quality and bug-bash process
  • Helped land GA-quality mobile experience — Gen3 architecture shipped and became foundation for Photos and monetization features
  • Multiple "missing files / broken recents" bugs closed post-migration — measurable platform stabilization

📖 Learning

Quality is built in the last 10% — and that 10% compounds, because the Gen3 foundation is what made every downstream Photos, storage, and monetization feature possible to build at all.
